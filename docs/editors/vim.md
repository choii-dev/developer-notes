### 一、 Vim 三大模式

Vim 默认为**普通模式**，无论按错什么，连续按两次 `Esc` 都能安全返回普通模式。

* **普通模式 (Normal Mode)**：默认模式，用于移动光标、删除、复制粘贴。
* **插入模式 (Insert Mode)**：用于文本输入。
* **底行模式 (Command-line Mode)**：用于保存、退出、查找与设置。

---

### 二、 核心基础操作

| 操作类型 | 命令 | 功能说明 |
| :--- | :--- | :--- |
| **进入输入** | `i` | 在光标**前**开始输入（最常用） |
| | `a` | 在光标**后**开始输入 |
| | `o` | 在光标**下一行**新建空行并输入 |
| **保存与退出** | `:w` | 保存文件 |
| *(底行模式)* | `:q` | 退出 |
| | `:wq` 或 `ZZ` | **保存并退出** |
| | `:q!` | **强制退出**（不保存修改） |

---

### 三、 光标移动 (普通模式)

| 命令 | 功能说明 |
| :--- | :--- |
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右（方向键同样有效） |
| `0` 或 `^` | 移动到**行首** |
| `$` | 移动到**行尾** |
| `gg` | 移动到文件**第一行** |
| `G` | 移动到文件**最后一行** |
| `<行号>G` 或 `<行号>gg` | 跳转到指定行（如 `15G` 跳转到第 15 行） |

---

### 四、 编辑、复制与撤销 (普通模式)

| 命令 | 功能说明 |
| :--- | :--- |
| `u` | **撤销**上一步操作 (Undo) |
| `Ctrl` + `r` | **重做**撤销的操作 (Redo) |
| `x` | 删除当前字符 |
| `dd` | **剪切/删除**当前整行 |
| `yy` | **复制**当前整行 |
| `p` | 在光标下方**粘贴** |
| `3dd` / `3yy` | 剪切/复制从当前行开始的 **3 行**文本 |

---

### 五、 搜索与替换 (底行模式)

| 命令 | 功能说明 |
| :--- | :--- |
| `/text` | 向下搜索 `text`（按 `n` 跳下一个，`N` 跳上一个） |
| `:%s/old/new/g` | 将全文所有的 `old` 替换为 `new` |
| `:%s/old/new/gc` | 全文替换，但每次替换前弹窗确认 |
